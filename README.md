# Library Management System

A Java desktop **Library Management System** built with **Java Swing**, applying object-oriented design to common library operations such as book management, borrowing, returns, validation, and reporting.

## Features

- Add, search, update, and delete books
- Borrow and return books
- File-based persistence
- Statistics dashboard
- Input validation
- Exception handling
- Modular GUI, model, service, and utility layers

## Tech Stack

- Java
- Java Swing
- OOP
- ArrayList
- File I/O
- Exception Handling

## Engineering Notes

The project focuses on applying Java OOP concepts to a complete desktop workflow rather than isolated language exercises. Business operations are separated from the Swing presentation layer to keep the application easier to maintain and extend.
